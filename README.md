# StatusBox

StatusBox is an Android application that lets you **save, view, and share WhatsApp-style statuses** – both images and videos – with a clean and intuitive interface. Designed for speed, simplicity, and a smooth user experience, StatusBox helps you **keep your favorite statuses forever**.

---

## 📱 Features

- **View Statuses:** Browse all image and video statuses saved from your WhatsApp or other apps.
- **Full-Screen Viewer:** Watch videos or view images in full-screen mode with easy controls.
- **Download Statuses:** Save statuses directly to your gallery with one tap.
- **WhatsApp-Like Design:** Clean, modern UI inspired by WhatsApp themes for a familiar experience.
- **Video & Image Support:** Automatically detects and separates videos and images.
- **Ripple Animations:** Smooth circular ripple effects for interactive buttons.
- **Safe File Handling:** Automatically handles duplicate filenames when saving.

---

## 🌈 UI Highlights

- **Tabs & Swipe:** Easy navigation between image and video statuses.
- **Floating Action Button (FAB):** Quick access to save or search statuses.
- **Premium Badge:** Option to highlight premium content or PRO features.
- **Custom Colors:** WhatsApp-style green gradients and smooth dark/light theme support.
